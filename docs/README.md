## Documentation Guidelines

When adding new documentation:
1. Place it in this `/docs` directory
2. Use descriptive filenames in lowercase with hyphens (e.g., `user-guide.md`)
3. Update this README.md with a brief description and link
4. Keep the root-level README.md focused on quick start information only
